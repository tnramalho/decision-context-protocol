# Decision Context Protocol

Este projeto usa DCP para registrar decisões, progresso e contexto técnico compartilhado.

## Regras

1. Sempre ler `snapshot.md` primeiro.
2. Não carregar o repositório inteiro.
3. Novas contribuições devem ir para `inbox/`.
4. Decisões oficiais devem ficar em `decisions/`.
5. Nada vira decisão oficial sem confirmação humana.
