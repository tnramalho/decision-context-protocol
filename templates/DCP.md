# Decision Context Protocol

This repository uses DCP to register decisions, progress and shared technical context.

## Rules

1. Always read `snapshot.md` first.
2. Do not load the whole repository.
3. New contributions go to `inbox/`.
4. Official decisions live in `decisions/`.
5. Nothing becomes an official decision without human confirmation.
6. One session must use only one active repository.
7. Contributions are append-only by default.
8. Consolidation only happens with explicit user intent.
